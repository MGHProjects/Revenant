      What rises from a document

      • Alive

        The link still answers with the page you cited.

      • Dead

        Nothing answers: a 404, a 410 or a domain that no longer exists. The stone's height is how long the page lived in the archive.

      • Possessed

        The address answers, but it now leads to another site that does not show what you cited.

      • Restless

        The site would not answer a robot, or took too long. Revenant does not guess.

      Three doors

      • This page: paste a README or give it a repo, and the graveyard shows what died.
      • The command line: fails a CI job when a README has dead links.
      • The MCP server: lets an agent check a link before it cites it.
